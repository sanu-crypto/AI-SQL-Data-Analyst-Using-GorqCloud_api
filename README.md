📊 AI SQL Data Analyst Agent

An AI-powered SQL Data Analyst application built using Python, Streamlit, SQLite, LangChain, and Groq LLaMA 3 model.

This project allows users to upload CSV datasets, ask questions in natural language, automatically generate SQL queries using AI, execute them on a SQLite database, and visualize results with charts.

🚀 Features
📂 Upload CSV datasets
🧠 AI-generated SQL queries
💬 Natural language data analysis
🗄️ Automatic SQLite database creation
📊 Interactive data visualization
⚡ Real-time query execution
🎨 Streamlit web interface
🔥 Powered by LLaMA 3 via Groq API
🛠️ Technologies Used
Technology	Purpose
Python	Backend development
Streamlit	Frontend web application
Pandas	Data handling
SQLite	Database
LangChain	LLM integration
Groq API	AI model inference
LLaMA 3	SQL generation
Matplotlib	Data visualization
